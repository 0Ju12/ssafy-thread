# 관통 1 · Python 도서 데이터 분석 (2026.07.29)

JSON 형식의 도서 데이터를 읽어 목적에 맞게 가공·집계하는 Python 프로그램입니다.

## 기술
Python 3.11 · `json` · `pathlib` · List/Dictionary · `lambda` · `sorted()`

## 구현한 기능
- 도서 제목 리스트 생성, 평균 판매 가격·고객 리뷰 계산, 도서별 작가 정보 추출
- 가격대별 분류, 어린이 도서 필터링
- 출판사별 도서 수, 카테고리별 도서 수·평균 가격 집계
- 최신 도서 10권, 할인율 상위 5권 조회

## 어려웠던 점과 해결
- **JSON 구조 파악:** 데이터를 먼저 출력해 구조를 분석한 뒤 필요한 값을 추출
- **카테고리·출판사별 집계:** Dictionary로 값을 누적하는 구조를 설계하고, 기능을 작은 단위로 나눠 중간 결과를 확인하며 디버깅
- **추출 → 가공 → 집계 → 정렬** 순서로 구현하는 습관을 들임

## 느낀 점과 보완 방향
데이터를 단순히 출력하는 것이 아니라 **원하는 형태로 가공하는 과정**이 중요하다는 것을 배웠습니다.
함수화로 재사용성을 높이고, 예외 처리를 추가하고, pandas·Matplotlib로 분석·시각화를 확장하고 싶습니다.
