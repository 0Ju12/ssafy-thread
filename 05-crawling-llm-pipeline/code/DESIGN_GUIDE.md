# ThRead 디자인 추가 가이드 (총 11가지)

기존 A–F 6종은 그대로 유지하고, 아래 5종을 추가했습니다. **크롤링·LLM·DB 코드는 변경하지 않았습니다.**

| ID | 신규 테마 | 구조 | 특징 |
|---|---|---|---|
| `aurora` | G 오로라 AI | 3단 데이터 비교 | 블루·퍼플 그라데이션, 대형 히어로, 부드러운 카드 |
| `atelier` | H 아틀리에 리서치 | 3단 데이터 비교 | 아이보리·딥그린, 편집 디자인, 차분한 리포트 |
| `brutal` | I 네오 브루탈 | 스토리 레이아웃 | 고대비 컬러, 검은 테두리와 오프셋 그림자, 강한 타이포 |
| `glass` | J 소프트 글래스 | 사이드바 + 탭 | 반투명 글래스 패널, 파스텔 배경, 정보 중심 |
| `console` | K 터미널 프로 | 사이드바 + 탭 | 짙은 배경, 민트 포인트, 개발자 분석 콘솔 |

## 선택 방법

1. `python manage.py runserver`로 실행합니다.
2. 화면 **우하단 '✦ 디자인 선택'** 버튼을 누릅니다.
3. 원하는 A~K 디자인을 선택합니다. 검색과 결과 페이지에 적용됩니다.
4. `.env`에 `UI_THEME=glass`처럼 적으면 기본 테마를 고정할 수 있습니다.
5. 선택 UI를 숨기려면 `.env`에 `SHOW_THEME_SWITCHER=0`을 쓰고 서버를 재시작합니다.

빠른 링크: `http://127.0.0.1:8000/?theme=aurora`, `?theme=atelier`, `?theme=brutal`, `?theme=glass`, `?theme=console`

주의: 새로운 5개 테마는 화면 표현 전용이며 댓글 분포 차트나 감성 분석처럼 기존 백엔드에서 계산하지 않는 기능은 추가하지 않았습니다. 전용 테마 CSS는 `comments/static/comments/css/theme-*.css`에 있습니다.
